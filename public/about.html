ABOUT THE BLOG

WELCOME TO
LEONIDA 🌴

A fan-made GTA VI blog with official videos and confirmed facts only — no rumors, no intox. Running on a hand-rolled pure C HTTP server with FlashDB (KVDB + TSDB) as the database. No PHP, no Node, no framework. Just sockets, neon and Vice City dreams.

⚡ Pure C

Single server.c: POSIX sockets, pthreads, hand-parsed HTTP + JSON. Static files are pure HTML/CSS/JS + Bootstrap 5.

💾 FlashDB

Real armink/FlashDB in Linux file mode. Posts/comments in KVDB, views & events in TSDB.

✅ Official only

Every post is a Rockstar video or a confirmed fact — trailers, the Extended Look, release date, price, platforms. No rumors, no intox.
